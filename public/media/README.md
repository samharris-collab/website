# Imagery

The files here are art-directed vector compositions generated by
`scripts/generate-placeholders.mjs`. They exist because the rebuild environment
could not reach the live site to download the original photography.

They are sized to the slots they fill, so layout, LCP and CLS are already
correct. To use real photography, overwrite the file at the same path with the
same aspect ratio:

| File | Ratio | Where it appears |
| --- | --- | --- |
| `hero-media.jpg` | 2.4:1 | Homepage hero (the only `priority` image on the site) |
| `about-media.jpg` | 4:3 | "About DNA PR" |
| `client-testimonial-poster.jpg` | 16:9 | Video testimonial poster frame |
| `placement-kirk-msn.jpg` | 4:3 | Case study — Dr. Kirk Sanford |
| `placement-brick.jpg` | 4:3 | Case study — Matthew Brick |
| `placement-indran.jpg` | 4:3 | Case study — Dr. Bhuvanendram Indrakrishnan |
| `placement-albright.jpg` | 4:3 | Case study — Andréa Albright |
| `placement-kelly.jpg` | 4:3 | Case study — Patrick Kelly |

`next/image` re-encodes to AVIF/WebP and generates the responsive set, so commit
the highest-quality original you have rather than a pre-optimised one.
